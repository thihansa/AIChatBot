# AIChatBot

Flask Chatbot with Mistral API

A simple chatbot web application built using Flask and Mistral AI API.
Users can send messages through a web interface, and the bot responds in real-time.

Features

- Simple web-based chat interface
- Real-time communication using Fetch API
- Integration with Mistral AI for responses
- Lightweight and easy to extend

Tech Stack

- Backend: Python (Flask)
- Frontend: HTML, JavaScript
- AI: Mistral API
- Tunneling: Ngrok
